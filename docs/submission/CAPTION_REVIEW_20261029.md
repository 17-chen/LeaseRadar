十场景[有声浏览器稿](../../output/video/LeaseRadar_Full_Browser_Review_20261028.mp4)新增[中文VTT字幕](../../output/video/LeaseRadar_Full_Browser_Review_20261028.zh-CN.vtt)和[逐段稿JSON](../../output/video/LeaseRadar_Full_Browser_Review_20261028.captions.json)。字幕保留旁白稿所有文字，场景起点与音频长度来自已验证的成片时间线，句内时间按字数估算，**未做语音强制对齐或真人逐字听审**。MP4字节未改；下载后需另外加载VTT。

在仓库或完整审阅包根目录运行：

```sh
python3 scripts/serve_video_review.py --port 8017
```

打开终端显示的回环地址。服务只读取output/video中的直接文件，拒绝目录越界、符号链接及无关文件类型；仅监听127.0.0.1，支持单段HTTP字节范围。它用于本机合成媒体审阅，不是公网托管。标准库即可运行；Ctrl-C停止，端口占用时选择其他空闲端口。

审阅页默认显示字幕，可在播放器关闭。展开“逐段核对旁白与画面”，点击标题或用键盘Enter可定位十个场景；定位不会自动播放或保存人工签收。每段应记录错读、停顿、金额/状态/画面不符和遮挡的时间码，再决定修正与签收。字幕估算不能证明语音发音正确。

生成器`python3 scripts/build_browser_captions.py`拒绝覆盖；`--check`逐字节检查已有产物。输入绑定旁白稿哈希、成片证明、时长与十场景时间；文本空白/换行、重叠/越界、NaN/无穷、错误场景和虚假的听审声明均拒绝。完整包打包器重新生成预期字幕及逐段稿并比对，防止旁白或时间线改了却沿用旧字幕。
