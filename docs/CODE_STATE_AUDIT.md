## 界面评价与改进

原界面基础布局清晰，但比较选择跨页后不易看见、筛选区占用较大、比较缺少用途与核验时间，且未应用条件会在页面切换时生效。本次落实：

1. 常用条件优先，物业/环境/用途/价格性质/状态收进可展开的“更多筛选”；所有条件仍可自由选。城市/区县提供已见数据建议，也允许自由输入全称。
2. 已应用条件摘要与未应用草稿提示分开；只在应用后变化，旧请求不覆盖新结果。保存订阅展示实际订阅条件；订阅可一键查看匹配候选。刷新状态不会触发源站抓取。
3. 已选比较栏跨页、跨筛选保留，最多5条，可移除/清空；不足2条按钮禁用，退出清空。
4. 比较首行优先面积、月租基准、单位面积月租和报名期限；16项字段并列，差异行标记，unknown单独底色；价格性质按列分组，不把未知价格作0或最低成本。
5. 固定表头与字段列；依据详情可打开并返回比较；手机退出入口可见。去掉外部字体网络依赖。

真实浏览器通过草稿切页不生效、月租下限0+排除unknown得到6条、跨页比较、不同价格性质/未知列、查看依据返回、390px手机无页面横向溢出等操作。桌面比较宽度1180px，三条候选不需横向滚动；手机比较表在自身区域左右滚动。隔离DEMO验证订阅100㎡条件筛出2/3条合成记录，退出后清空私人DOM、另一账户看不到上一账户订阅/提醒。合成账户未进入真实库。
