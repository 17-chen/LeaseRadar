# 开发实施计划与验收清单

## 1. 时间假设与执行原则

以下是约4周的参考冲刺，假设1名主要开发者配合Codex、1名业务/数据复核者；实际工期取决于接入难度，不代表已确认截止日期。只有一人时按阶段交付，不为赶日历跳过可靠性。先真实纵向闭环，再扩来源与精度；每阶段有演示与检查记录。

## 2. 阶段0：来源与需求验证（参考第1–2天）

- [ ] 阅读交接文档；检查现有代码、AGENTS与环境，不覆盖AgentTwin。
- [ ] 建立Git仓库/目录、依赖基线与版本锁，记录尚未满足的凭据。
- [ ] 核实农交云公开列表/详情/分页/附件；记录实际访问与规则。
- [ ] 验证温州产权平台，403标blocked；查公开发布单位或浙交汇补充来源。
- [ ] 收集每个候选来源5–10条不同格式样本；标注价格周期/期限/状态。
- [ ] 输出SOURCE_AUDIT.md，含访问时间、成功范围、样本链接、分页与附件风险。
- [ ] 访谈负责人并保存真实订阅需求；未获取时继续用明确标注的示例值。

验收：至少一个来源能实际获取及解析；第二来源有接通路径或具体阻塞说明。日志不暴露账号/密钥。不得用搜索缓存代替真实适配器验证。

## 3. 阶段1：数据底座与首源闭环（参考第3–7天）

- [ ] FastAPI、Postgres、迁移、Celery/Redis、Compose可启动。
- [ ] 来源/采集任务/快照/公告/lot/资产/挂牌/版本/证据模型建立。
- [ ] 农交云adapter实现discover/fetch/parse与分页重试。
- [ ] 首批来源关键附件可解析；OCR仅在实际关键载体需要时加入。
- [ ] 金额Decimal、单位和日期precision，null不是0。
- [ ] 规则提取、字段依据、unknown和提取冲突队列。
- [ ] 初始认证、列表/详情API、最简手机页面。
- [ ] CLI统一入口可检查来源、运行一次采集、回放样本。

验收：用户登录后看到来自真实采集的房源，能查看价格/期限依据；一篇多lot公告不会被压成一套房源；重跑不产生重复源记录。

## 4. 阶段2：持续监测与可用提醒（参考第8–12天）

- [ ] beat单实例、来源锁、周期检查与每日补扫。
- [ ] 内容hash、活跃详情复查、明确状态优先、空解析异常检测。
- [ ] 订阅表单与三值匹配、未知策略、首次历史摘要。
- [ ] change_event、事务outbox、网页收件箱、local_test_sink。
- [ ] 一种外部通道实现并在授权测试地址验证；未配置明确disabled。
- [ ] 重试/死信、accepted与delivered区分、超时ambiguous处理。
- [ ] 报名期限提醒、延期取消旧任务、静默时间。
- [ ] 来源健康页面、管理员异常提醒、积压统计。

验收：定时出现新增样本→匹配→收件箱→测试通道；浏览器关闭仍运行；重启worker后待发事件继续；同事件无内部重复outbox。模拟来源失败时用户能看到数据可能不完整。

## 5. 阶段3：跨网站整合、去重与比价（参考第13–18天）

- [ ] 第二个真实独立来源接通，补充至3–5个为目标。
- [ ] 明确源记录/资产/挂牌关系与整体租赁bundle。
- [ ] 候选去重、强标识、硬冲突保护、人工合并/撤销。
- [ ] 重新挂牌时间线与多源字段冲突。
- [ ] 价格性质/计价周期/租金递增标准化，换算依据可见。
- [ ] 2–5条比较表：首年月租、平均租期月租、单位面积价区分。
- [ ] 链接/文件导入、人工纠正、再提取不伪造市场变化。
- [ ] 收藏、跟进状态、放弃原因、CSV安全导出。

验收：两个来源的同挂牌记录合并、重新挂牌仍保存新机会；未知价格周期不参加最低价排序；价格冲突有标记；不同铺号不误合并。列出已接通来源与未覆盖来源，不能只报总网站数。

## 6. 阶段4：真实上线、试用与比赛交付（参考第19–28天）

- [ ] 常驻服务器、HTTPS、secret、磁盘与worker限额、数据库非公网。
- [ ] 备份并实际恢复到新库验证。
- [ ] 100–200条标注评测集，按来源/公告批次防泄漏拆分。
- [ ] 建立同来源人工/关键词提醒/系统三组比较与消融。
- [ ] 3天影子运行，记录人工与系统发现时间及漏项。
- [ ] 7–14天真实试用，若冲刺时间不足则延续试用，不虚构完整时长。
- [ ] 修复负责人反馈，记录人均每天处理时间与候选价值。
- [ ] 中英README、贡献/安全/许可文件、CI、发行版本、路线图。
- [ ] 完整演示视频、运行命令、样本来源、实验原始数据与限制。

验收：负责人能独立登录、配置需求、收到真实提醒、查看原文和记录跟进；后台无人手动触发也能持续检查；所有性能数字均可从保存的原始结果复算。

## 7. 必须实现的回归用例

| 用例 | 预期 |
|---|---|
| 面积30/100㎡在边界 | 包含；未知面积进入unknown |
| 标题五年租赁权、价格120000无周期 | 不除以60，待确认 |
| 首年120000、面积60 | 10000/月，约166.67/㎡/月，有依据 |
| 首年价与成交价 | 不混排成同价性质 |
| 表格10个lot | 10个独立挂牌记录或按明确bundle处理 |
| 公寓楼内商铺 vs 整套公寓 | 类型与环境正确分开 |
| 未禁止餐饮 | 不推出明确允许咖啡 |
| 报名16日、竞价18日 | 16日后不推荐为可报名 |
| 发布时间只有日期 | 不制造精确分钟延迟 |
| 页首不变、深页回填 | 补扫发现，不永久漏掉 |
| 相同记录跨平台转载 | 合并出处，不重复新增提醒 |
| 同地址11号和111号 | 不自动合并 |
| 流标后新批次挂牌 | 新机会且保留历史 |
| 明确报名延期 | 更新提醒，旧任务取消 |
| 404一次 | 不直接判撤回 |
| 页面200但解析全空 | 来源降级，不报正常空结果 |
| LLM重新解析字段变化 | 标记再处理，非市场变化 |
| 两worker重复事件 | 一个业务事件和对应唯一outbox |
| 通道已接收但响应超时 | ambiguous，有可审查重试策略 |
| 未配置通道/AI | 系统仍可用，状态明确 |
| 文件含恶意宏/超大压缩/私网链接 | 拒绝或隔离，不能执行/访问 |
| member操作admin接口 | 403，无数据修改 |
| CSV以=或+开头字段 | 输出转义，防电子表格公式执行 |

## 8. 给Codex的建议命令契约

这些是待实现命令，不是现有可运行命令；Codex应提供实际入口并更新文档。

```bash
docker compose up --build -d
docker compose exec api python -m app.cli migrate
docker compose exec api python -m app.cli create-admin
docker compose exec worker python -m app.cli source-check nongjy
docker compose exec worker python -m app.cli crawl-once nongjy
docker compose exec worker python -m app.cli replay fixtures/demo_manifest.json
docker compose exec api pytest -q
```

create-admin通过交互或秘密环境变量，不在shell命令写真实密码；replay只写独立demo数据库或独立schema。迁移只在明确环境运行，不能自动清空现有库。

## 9. 交付完成标准

交付仓库、版本锁、迁移、Compose、来源配置模板、环境变量示例、fixture及测试、SOURCE_AUDIT、部署/恢复手册、评测脚本与结果模板、已知限制。每个阶段报告实际做了什么、如何验证、还缺什么；用“未验证”区分“通过”。不能把静态UI或模拟通知当成正式产品。
